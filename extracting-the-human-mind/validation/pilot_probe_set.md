# 파일럿 프로브 세트 (초안)

[파일럿](../architecture/pilot.md)에서 예측을 채점할 정답(hold-out)이 되는 문항. [검증 모드](validation_mode.md)의 최소 관문 배터리(라인업 A2 · 점예측 A1 · 재검사 천장 C1, 도메인당 앵커 ≥ 8)를 채우는 최소 구성이다. 서비스 코드는 `ethm-pilot` 저장소 `web/lib/modules/probes.ts`.

## 구성
> 탐색중

| 묶음 | 수 | 형식 | T1 | T2 | 쓰임 |
|---|---|---|---|---|---|
| 앵커 | 24 (일 8 · 관계 8 · 자기 8) | 상황 → 둘 중 하나 + 이유 한 줄(선택) | ○ | ○ | 점예측(A1), 안정 천장(C1), 모드 바닥 |
| 라인업 | 5 (일 2 · 관계 2 · 자기 1) | 문장 완성 빈칸 | ○ | — | 라인업(A2, 참가자 ≥ 5명), 자유 응답 예측 |
| 경제 게임 | 3 (general) | 독재자(0~100) · 최후통첩(제안 50/30/20/10 수락·거절) · 신뢰(0~100 보냄) | ○ | — | 가치 할당과의 갭, 행동 예측 |
| 자기 이해 | 1 | "나는 내 행동 패턴을 잘 안다." 1~7 | ○ | — | P-01 공변량 |

- **순서:** 앵커(일·관계·자기 번갈아) → 라인업 → 게임 → 자기 이해. 모두에게 같은 순서. 예측·점수·이전 답은 보여 주지 않는다.
- **재사용:** W1–W4 = [판단 시나리오](../extraction/judgment_scenarios.md)의 파일럿 미시행 딜레마(원칙과 성과 · 공과 사 · 충성심 vs 공평성 · 권위 vs 배려), W5·W8·R1·S1 = 검증 문서 예시(팀장 반대 · 상사/친구가 아이디어를 가져감 · 자율성 vs 안정성), L1–L4 = [생성 은유](../extraction/generative_metaphor.md)의 일·관계 덱 문장 완성(파일럿은 자기 덱만 시행), L5 = [이해 검증](comprehension_validation.md) 예시. 나머지 앵커 16개와 게임 문구는 새로 썼다.
- **게임:** 가상 코인(실제 돈 없음). 한국 표본 기준선이 없으므로 바닥은 표본 안 최빈값.

## 앵커 24
> 탐색중

모든 문항은 상황 문장 + 질문 + 두 선택지. 질문이 따로 없으면 "어떻게 하겠는가?".

| ID | 도메인 | 상황 | 선택지 |
|---|---|---|---|
| W1 | 일 | 팀이 큰 실적을 낼 기회. 잡으려면 내부 규정을 편법으로 우회해야 하고, 타 팀은 관행적으로 그렇게 한다. | 규정을 우회해 기회를 잡는다 / 규정대로 하고 기회를 놓친다 |
| W2 | 일 | 평가할 팀원이 비극적인 가족사로 업무를 완전히 망쳤다. 원칙대로 최하점이면 해고될 수 있다. | 원칙대로 최하점 / 사정을 반영해 점수를 올림 |
| W3 | 일 | 오래 헌신한 부하 직원이 천재적인 신입에게 승진에서 밀릴 위기. 부하 직원이 당신에게 기댄다. (누구를 추천?) | 오래 함께한 부하 직원 / 더 뛰어난 신입 |
| W4 | 일 | 상사 방식대로면 절차는 깔끔하지만 하청 노동자가 주말 내내 과로한다. 다른 방식 제안은 상사 권위를 들이받는 셈. | 상사 방식대로 / 다른 방식 제안 |
| W5 | 일 | 새 직장에서 팀장이 당신의 안에 반대한다. 당신은 당신 안이 낫다고 확신한다. (팀장이 반대해도 밀어붙이겠는가?) | 밀어붙인다 / 팀장 안을 따른다 |
| W6 | 일 | 마감 이틀 전 동료 파트의 큰 실수를 당신만 알아챘다. 회의에서 말하면 동료가 곤란해진다. | 회의에서 바로 짚는다 / 조용히 대신 고쳐 둔다 |
| W7 | 일 | 연봉 20% 더·야근 잦음 vs 연봉 그대로·정시 퇴근 보장. (어디로?) | 연봉이 높은 회사 / 정시 퇴근 회사 |
| W8 | 일 | 당신이 거의 다 한 일을 상사가 회의에서 자기 아이디어처럼 발표했다. | 그 자리에서 내 기여를 밝힌다 / 그 자리에서는 넘어간다 |
| R1 | 관계 | 친한 친구가 당신이 지나가듯 말한 아이디어로 사업을 시작해 반응이 좋다. 당신에겐 아무 말이 없었다. | 서운하다고 직접 말한다 / 아무 말 하지 않는다 |
| R2 | 관계 | 가장 가까운 사람이 당신이 정말 싫어하는 모임에 꼭 같이 가자고 한다. | 같이 간다 / 솔직히 싫다고 하고 빠진다 |
| R3 | 관계 | 친구가 큰돈을 빌려 달라고 한다. 갚을 수 있을지 불확실하다. | 빌려준다 / 거절한다 |
| R4 | 관계 | 친구의 연인이 다른 사람과 다정하게 있는 걸 봤다. 확실한 상황인지는 모르겠다. | 본 대로 말한다 / 말하지 않는다 |
| R5 | 관계 | 가족 모임에서 어른이 당신의 진로·생활 방식을 친척들 앞에서 깎아내린다. | 그 자리에서 반박한다 / 웃고 넘긴다 |
| R6 | 관계 | 단체 대화방에서 다들 자리에 없는 한 친구를 은근히 놀린다. | 그만하자고 끊는다 / 가만히 있는다 |
| R7 | 관계 | 혼자 쉬기로 한 주말, 오랜만에 연락한 친구가 지금 만나자고 한다. | 만나러 나간다 / 다음에 보자고 한다 |
| R8 | 관계 | 가까운 사람과 크게 다툰 뒤 사흘째 연락이 없다. 상대 잘못이 더 크다고 느낀다. | 내가 먼저 연락한다 / 연락을 기다린다 |
| S1 | 자기 | 안정적인 지금 일을 그만두고, 수입이 불확실한 채 하고 싶던 일을 시작할 기회. | 새 일을 시작한다 / 지금 일을 지킨다 |
| S2 | 자기 | 몇 달 준비한 시험·프로젝트를 이번엔 망칠 것 같다. 지금 그만두면 들인 것은 날아간다. | 끝까지 해 본다 / 지금 그만둔다 |
| S3 | 자기 | 아무 일정 없는 일요일이 통째로 생겼다. (어떻게 보내겠는가?) | 미뤄 둔 일을 처리한다 / 아무것도 안 하고 쉰다 |
| S4 | 자기 | 여러 사람 앞 발표 기회. 잘하면 인정, 실수하면 오래 기억된다. | 맡는다 / 다른 사람에게 넘긴다 |
| S5 | 자기 | 건강검진에서 생활 습관을 바꾸라는 말을 들었다. 당장 아픈 곳은 없다. | 이번 주부터 바꾼다 / 당분간 지금처럼 |
| S6 | 자기 | 연고 없는 도시에서 1년 살아 볼 기회가 생겼다. | 떠난다 / 남는다 |
| S7 | 자기 | 갖고 싶던 비싼 물건이 오늘만 크게 할인. 사면 이번 달이 빠듯하다. | 산다 / 사지 않는다 |
| S8 | 자기 | 오래 해 온 취미가 요즘 즐겁지 않다. 계속하면 실력은 는다. | 계속한다 / 그만둔다 |

참가자 화면의 정확한 문구는 서비스 코드(`probes.ts`)에 있고, 위 표는 그 요약이다.

## 라인업·게임 문구
> 탐색중

- L1 "상사나 회사가 나를 평가할 때, 내가 가장 예민하게 반응하는 지점은 [ ] 이다." · L2 "관계에서 나를 가장 비참하게 만드는 상대의 행동은 [ ] 이다." · L3 "일이 내 통제를 완전히 벗어나 망해갈 때, 나는 무의식적으로 [ ] 한다." · L4 "누군가 내 선을 넘었다고 느낄 때, 내가 겉으로 취하는 첫 행동은 [ ] 이다." · L5 "나의 가장 큰 약점은 [ ] 이다."
- G1 독재자: 100코인을 모르는 다른 참가자와 나눈다, 상대는 거절할 수 없다 → 몇 코인을 주겠는가.
- G2 최후통첩(응답자): 상대가 100코인 중 50·30·20·10을 제안 → 각각 받는다/거절한다(거절하면 둘 다 0).
- G3 신뢰: 보낸 코인은 세 배가 되어 상대에게 가고 상대가 돌려줄 양을 정한다 → 몇 코인을 보내겠는가.

## 미결 사항

- [User Review] 이 세트 전체 확정(런칭 전) — 특히 새로 쓴 앵커 16개의 문구와 도메인 배정, 둘 중 하나 형식(리커트·자유 서술 대신), 게임 3종 선택. 이유: 문서에 프로브 문항이 없어 초안을 썼고, 런칭 뒤 바꾸면 Q1 비교가 깨진다.
- [User Review] 뺀 것 — 즉시 재질문 천장(분모가 아님)·자기 예측 먼저(PT-4)·행동 예측 + ESM 추적(PT-6)·편향 과제(A7)·외부 척도(PT-10)는 파일럿 T1에 넣지 않았다. 넣으려면 T1 길이(현재 약 25분)와 함께 정한다.
