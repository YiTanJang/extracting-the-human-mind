# 전역 미답 질문 (Open Questions)

번들 전체를 블로킹하는 연구 질문을 모은다. 각 파일 하단의 로컬 `## 미결 사항`과 구분된다(이 파일 = 프로젝트 전역, 로컬 = 그 파일의 설계 결정). Q 번호는 추가 순서 기준이며 재번호하지 않는다.

## 질문 목록

### Q1. "구조가 활성 성분"인가 — 분량매칭 베이스라인 대비 증분 타당도

**상태**: 미답
**Phase**: Phase 0 Showstopper
**핵심 갈등**: 구조화 배터리가 예측을 이겨도, 그것이 *구조* 때문인지 단지 *더 많이·오래 캐냈기(분량)* 때문인지 가릴 수 없다.
**왜 중요한가**: 주장 A(구조 고립)가 깨지고 B(실용 우위)만 남으면, 본 시스템은 "구조적 추출 방법론"이 아니라 "더 많이 캐는 자기보고 도구"로 격하된다. 프로젝트의 존재 이유가 걸린 질문.
**현재까지 아는 것**: 검증 모드 A4(증분 타당도)가 이 판정을 담당. 1차 적은 soul.md가 아니라 *분량(단어수·시간) 매칭 자유 자기개방*.
**탐색 방향**: `validation/`의 A4 프로토콜 구체화. → [validation/validation_mode.md](../validation/validation_mode.md)

### Q2. 인지 엔진 4+1은 동일 호출수의 단순 앙상블을 이기는가

**상태**: 미답
**Phase**: Ph2 (활용 단계)
**핵심 갈등**: 4+1 다중 에이전트(역할 분할)의 이득이 역할 분할 자체에서 오는가, 아니면 단지 호출 횟수가 늘어서인가.
**왜 중요한가**: A1 교란변수 ablation(4+1 vs sampling-and-voting 같은 호출수)에서 못 이기면 역할 분할은 장식일 뿐이다.
**현재까지 아는 것**: 외부 문헌(Smit 2311.17371, Li 2402.05120)은 MAD 이득이 주로 호출수에서 온다고 경고. 대조군: 역할 셔플, 붕괴 측정(CoMPosT).
**탐색 방향**: `architecture/cognitive_engine.md`의 검증 계획(A1~A3) 구체화.

### Q3. 한국 문화권 경제 게임 행동 기준선 확보

**상태**: 미답
**Phase**: Ph1
**핵심 갈등**: 경제 게임(신뢰·독재자 게임 등) 기준선은 문화권마다 다른데, 검증에 쓸 한국 현지 baseline이 없다.
**왜 중요한가**: 정규화 정확도의 '바닥'을 잘못 잡으면 예측 성능이 과대/과소 평가된다.
**현재까지 아는 것**: Camerer(2003)는 문화적 특수성을 경고. 현지 기준선 병행 필요.
**탐색 방향**: 한국 표본 경제 게임 기준치 수집 또는 문헌 확보. → [research/related_research.md](related_research.md) §2

### Q4. inbox 원본 문서의 OKF 이관 완료

**상태**: 해결 (2026-07-16)
**Phase**: Phase 0 Showstopper
**핵심 갈등**: 마이그레이션 초기엔 스켈레톤 + 3종만 이관돼 나머지 원본이 `inbox/`(gitignore)에만 존재하고 번들 링크가 깨져 있었다.
**왜 중요한가**: 남은 원본이 이관되기 전까지 번들은 불완전하고, 원본이 git 이력에만 있어 협업/공유가 제한된다.
**해결 내용**: 원본 34개 전부를 OKF 개념 문서로 이관 완료(frontmatter·상대경로 링크·`## 미결 사항`, 본문 verbatim). 링크 무결성·본문 줄 수 검증 통과. 상세는 [log.md](../log.md) 2026-07-16 항목.
**남은 결정(전역 아님)**: 저장소 루트 `okf-system/`을 커밋할지 gitignore할지, 전체 변경 커밋 여부는 사용자 결정 대기 — 연구 질문이 아니라 운영 결정이라 여기서 종결.
