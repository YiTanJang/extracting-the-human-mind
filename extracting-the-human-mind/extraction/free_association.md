# Methodology: 자유연상 (Free Association)

> **상태: 후보 모듈 (탐색중)** — 아직 16종 배터리에 정식 편입 확정이 아니다. EFT·애착 서사 완성과 동일하게 검증 모드 A4(증분 타당도) 통과를 편입 조건으로 둔다.
>
> **예상 소요 시간:** 3~6분 (사용자가 멈출 때까지)
>
> **세 줄 요약:**
> - 자극이 되는 단어조차 주지 않고, 지금 떠오르는 단어들을 검열 없이 순서대로 흘려 적게 한다.
> - 무엇이 떠올랐는지, *언제 막혔는지(지연·긴 정지)*, 떠오르지 않음·거부까지 전부 날것으로 남긴다.
> - 어떤 프레임도 없는 가장 순수한 L1 신호 — 은유·상징 같은 설계자 틀 없이 단어 그 자체만 추출한다.
>
> **설계 핵심:**
> - **핵심 원리:** 자극어조차 없는 순수 연상은 설계자 프레임을 원천 제거해, 개인 고유의 의미 연결망을 가장 오염 없이 드러낸다.
> - **방식:** 정적 검사(LLM 루프 밖). 다만 반응지연(RT)은 §1-2 원칙의 *명시적 예외*로 수집한다(아래 §1).
> - **결과물:** (연상 단어 스트림 + 각 단어의 입력 시각 + 막힘/정서 자기보고)의 verbatim 배열.

## 0. 이론적 전제 및 설계 원칙

- **이론적 기원:** 정신분석의 자유연상. 규준(nomothetic) 점수화가 아니라 **idiographic** — 개인 고유의 연상 내용·흐름을 raw로 보존한다.
- **자극어 없음 (Frame-free, 순수):** 표준 단어연상검사(WAT)와 달리 **자극어를 제시하지 않는다.** 설계자가 단어를 고르는 순간 프레임이 주입되므로, 자극을 완전히 제거해 무오염 원칙([../overview/principles.md](../overview/principles.md) §1-0 5항)을 **가장 강하게** 만족시킨다. 은유·상징 풍경 같은 *틀*을 주는 다른 L1 기법([생성 은유와 문장 완성](generative_metaphor.md)·[클린 랭귀지](clean_language.md))과 대비되는, 순수 어휘 연상이라는 점이 이 모듈의 정체성이다.
- **독립 모듈:** 자극이 raw에서 파생되지 않으므로 선행 의존이 없고 자기순환 위험도 없다.
- **Verbatim·무프로빙:** 연상어는 정규화·요약 없이 그대로. 스트림이 짧거나 비어도 꼬리질문하지 않는다(막힘 자체가 데이터).

> 가설: 프레임 없는 순수 단어 연상이, 이미 L1을 담당하는 [삼항 도출](triad_elicitation.md)·[생성 은유와 문장 완성](generative_metaphor.md)·[클린 랭귀지](clean_language.md) 위로 *증분* 예측 신호를 준다. 이 가설이 참이어야만 배터리에 편입한다([검증 모드](../validation/validation_mode.md) A4).

## 1. 반응지연(RT) 예외 수집
> ⚠️ 원칙 위배 명시

본 프로젝트는 밀리초 단위 반응속도 측정을 웹 환경 제약을 이유로 **기각**했다([../overview/principles.md](../overview/principles.md) §1-2, [번들 index](../index.md) 설계 결정 테이블). **자유연상 모듈은 그 전역 원칙에 대한 명시적 예외다.** 자유연상에서는 단어 사이 지연·최초 지연·긴 정지(막힘)의 *시간 구조*가 그 자체로 억압·정서적 걸림을 가리키는 심리 신호일 수 있어, 예외적으로 입력 시각을 수집한다.

- **전역 기본은 여전히 '제외'다.** RT는 특정 모듈이 정당화와 함께 예외를 선언할 때만 켜며, 현재 그 대상은 자유연상 하나뿐이다.
- **웹 측정 한계 인정(원래 기각 사유):** 브라우저 RT는 네트워크·렌더·입력 지연으로 노이즈가 크다. 따라서 RT를 정밀 ms 지표로 쓰지 않고, **같은 세션 내 상대적 지연·긴 정지 플래그**라는 *보조 신호*로만 사용한다. 절대값으로 개인 간 비교하지 않는다.
- **교차 해석:** RT의 막힘 신호는 사용자의 self-report 막힘("여기서 한참 막혔어요")과 **교차**로만 해석한다(둘이 같은 지점을 가리키면 신뢰↑).

> 가정: 예외적으로 수집한 RT가 방법의 예측 가치에 유효하게 기여한다. (깨지면 → RT 수집을 철회하고 순수 내용·자기보고로 회귀. §1-2 전역 원칙과 완전히 정합해진다.)

## 2. 수행 절차

1. **개시:** 자극 없이 안내만 제시한다 — "지금 머릿속에 떠오르는 단어들을, 검열하지 말고 떠오르는 순서 그대로 적어주세요."
2. **스트림 입력:** 단어/짧은 구를 하나씩 입력. 각 단어를 verbatim + 입력 시각(§1)으로 저장.
3. **막힘·거부:** "안 떠오름 / 멈추기 / 이 흐름 불편"을 언제든 선택 가능. 이 반응 자체와 그 시점의 긴 정지를 데이터로 저장(강제 진행 없음).
4. **종료:** 사용자가 멈출 때 종료. 최소 개수를 강제하지 않는다.

## 3. 세션 격리 규칙 (Same-Day Isolation) — 필수

**자유연상은 다른 어떤 심리 검사와도 같은 날 실시하지 않는다.** 다른 기법(은유·삼항·인생 장면·CCRT 등)이 특정 개념·정서를 점화(priming)하면 그 잔상이 '자유' 연상 스트림에 스며들어 순수성이 깨진다 — 방금 삼항에서 '통제'를 다뤘다면 자유연상에 '통제'가 튀어나오는 것이 진짜 연상인지 점화 잔상인지 가릴 수 없다. 순수 연상은 다른 과업의 점화로부터 **격리된 날**에만 유효하다.

- 앱은 같은 날 다른 검사 제출 기록이 있으면 자유연상 진입을 막고 다음 날로 유도한다.
- 이 격리 여부를 산출물에 `administered_alone` 플래그로 감사한다.

## 4. 산출물 및 데이터 저장 (Raw Store Append)

```yaml
  - id: fa0001
    ts: 2026-07-16T21:00:00+09:00
    method: free_association
    domain: general               # 자극 없음 → 보통 사후 도메인도 General
    administered_alone: true       # 같은 날 다른 검사 없음(§3 격리 규칙 감사)
    words:                         # 순수 연상 스트림, verbatim 순서
      - {w: "바다",  t_ms: 0}
      - {w: "떠남",  t_ms: 1900}
      - {w: "(막힘)", t_ms: 8200}  # 긴 정지 자체가 신호(RT 예외 수집)
    self_report: "‘떠남’ 다음에 한참 막혔어요"   # 없으면 생략
    rt_caveat: "browser-approx"    # 정밀 ms 지표 아님(§1) 명시
```

## 5. 알려진 한계 (Limitations)

- **RT 측정 타당도(§1):** 웹 노이즈로 정밀도가 낮아 보조 신호로만 쓴다. 정밀 콤플렉스 지표로 오용 금지.
- **원칙 위배:** §1-2 전역 원칙에 대한 예외다. RT 수집을 다른 모듈로 확대하려면 매번 별도 정당화가 필요하다.
- **언어 유창성 교란:** 빈약한 스트림이 심리적 억압인지 단순 어휘력·상상 습관 때문인지 단독으로는 가릴 수 없다 → ESM·다른 L1 모듈과 교차검증으로만 해석.
- **직교성 미확정:** 이론상 순수 단어라 은유·클린과 구분되나, [검증 모드](../validation/validation_mode.md) A4 증분 타당도로 실증하기 전까지는 중복 가능성을 열어둔다(중복이면 흡수/기각).

## 6. UI 렌더링 명세 (Frontend Component)

- **UI 컴포넌트:** 자극 카드 없음. 빈 스트림 입력창 + "멈추고 싶으면 언제든" 버튼.
- **상호작용:** 사용자에겐 타이머·정답·점수를 보이지 않는다(입력 시각은 내부에서만 기록). "안 떠오름/멈추기"를 항상 노출해 막힘을 1급 데이터로 존중한다.
- **진입 게이트:** §3 격리 규칙에 따라, 같은 날 다른 검사 기록이 있으면 진입을 차단하고 안내한다.
