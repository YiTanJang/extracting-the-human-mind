# Methodology: 자유연상 (Free Association / Word Association)

> **상태: 후보 모듈 (탐색중)** — 아직 16종 배터리에 정식 편입 확정이 아니다. EFT·애착 서사 완성과 동일하게 검증 모드 A4(증분 타당도) 통과를 편입 조건으로 둔다.
>
> **예상 소요 시간:** 3~6분 (자극어 수·연쇄 여부에 따라 변동)
>
> **세 줄 요약:**
> - 자극이 되는 단어를 하나 보여주고, 즉시 떠오르는 단어/짧은 구를 그대로 적게 한다.
> - 무엇이 떠올랐는지뿐 아니라 *떠오르지 않음·불편함·거부* 자체도 날것으로 수집한다.
> - 개인 고유의 연상 네트워크(무의식적 연결)를 라벨 없이 원본으로 남긴다.
>
> **설계 핵심:**
> - **핵심 원리:** 자극어에 대한 즉발 연상은 의식적 편집을 우회해 개인 고유의 의미 연결망을 드러낸다.
> - **방식:** 정적 검사(LLM 루프 밖). 자극어 세트는 사전에 확정, 추출 중 LLM이 개입해 요약·유도하지 않는다.
> - **결과물:** (자극어 → 연상어열 + 막힘/정서 자기보고)의 verbatim 배열.

## 0. 이론적 전제 및 설계 원칙

- **이론적 기원:** Jung의 단어연상검사(Word Association Test)와 정신분석의 자유연상. 단, 본 모듈은 규준(nomothetic) 점수화를 목표로 하지 않고 **idiographic** — 개인 고유의 연상 내용을 raw로 보존한다.

> 가설: 자극어에 대한 즉발 연상(및 막힘의 위치)이, 이미 L1을 담당하는 [삼항 도출](triad_elicitation.md)·[생성 은유와 문장 완성](generative_metaphor.md)·[클린 랭귀지](clean_language.md) 위로 *증분* 예측 신호를 준다. — 이 가설이 참이어야만 배터리에 편입한다([검증 모드](../validation/validation_mode.md) A4).

- **반응시간(RT) 제외:** 전통 WAT는 반응지연을 콤플렉스 지표로 쓰나, 본 프로젝트는 밀리초 단위 반응속도 측정을 웹 환경 제약으로 **기각**했다([../overview/principles.md](../overview/principles.md) §1-2 주). 따라서 RT 대신 ① 연상의 *내용*, ② 사용자가 **자기보고**한 막힘·거부·정서("잘 안 떠올라요", "이 단어 불편해요")를 verbatim으로 포착한다. 시스템이 지연시간을 몰래 측정하지 않는다.
- **Verbatim·무프로빙:** 연상어는 정규화·요약 없이 그대로. 답이 짧거나 비었어도 꼬리질문하지 않는다(막힘 자체가 데이터).
- **정적 수행:** 자극어 세트는 사전 산출되며, 추출 중 LLM 챗봇을 쓰지 않는다([../architecture/architecture.md](../architecture/architecture.md) Module 1의 '정적 검사' 경로).

## 1. 자극어 세트 결정
> 탐색중

자극어를 제시하는 것 자체가 **설계자 프레임**이므로, "고정된 메뉴에서 선택하게 하지 않는다"는 무오염 원칙([../overview/principles.md](../overview/principles.md) §1-0 5항)과 정면으로 긴장한다. 단어를 *선택*하게 하는 것은 아니지만(사용자가 스스로 연상어를 생성), *어떤 단어로 자극할지*는 여전히 설계자가 정한다. 세 가지 선택지가 있고 아직 확정되지 않았다:

- **(A) 표준 고정 리스트:** WAT 전통의 표준 자극어. 개인 간 비교(nomothetic 준거) 가능하나, 본 시스템의 반-메뉴·개인고유 철학과 가장 충돌한다.
- **(B) 사용자 raw 파생 자극어:** 삼항 구성개념·[두려운 자기](feared_self.md) 상징·[클린 랭귀지](clean_language.md)에서 사용자가 띄운 상징을 자극어로 재사용(→ 의존 모듈). 가장 idiographic하나, 같은 raw를 재입력받는 **자기순환** 위험이 있어 증분 타당도 해석이 어려워진다.
- **(C) 중립 최소 시드 + 사용자 확장:** 극소수의 도메인 중립 시드(일/관계/자기)만 주고, 이후 자극어를 사용자 직전 연상어에서 잇는다(연쇄, §2). 프레임을 최소화한다.

## 2. 수행 절차

1. **제시:** 자극어 1개를 카드로 보여준다.
2. **즉발 연상:** 떠오르는 단어/짧은 구 1~3개를 입력. 순서대로 verbatim 저장.
3. **연쇄(선택):** 마지막 연상어를 다음 자극으로 삼아 1~2회 이어간다(단어 단위 체이닝, [클린 랭귀지](clean_language.md)의 상징 전개와 유사하되 *단어* 단위).
4. **막힘·거부:** "안 떠오름 / 넘어가기 / 이 단어 불편"을 언제든 선택 가능. 이 반응 자체를 verbatim 태그로 저장(강제 진행 없음).

## 3. 산출물 및 데이터 저장 (Raw Store Append)

```yaml
  - id: fa0001
    ts: 2026-07-16T21:00:00+09:00
    method: free_association
    domain: relation                 # 사후 도메인 태깅(General 허용)
    stimulus: "집"                    # 제시된 자극어
    stimulus_source: "C-seed"        # 감사 로그: A-standard / B-derived:<출처 id> / C-seed
    responses:                       # 즉발 연상, 사용자 원문 순서대로
      - "무거움"
      - "돌아가기 싫은"
    chain:                           # 연쇄 수행 시(선택)
      - stimulus: "돌아가기 싫은"
        responses: ["도망", "바다"]
    self_report: "‘집’에서 한참 막혔어요"   # 사용자 자기보고(막힘·정서). 없으면 생략
```

## 4. 알려진 한계 (Limitations)

- **자극어 프레임 오염(핵심):** §1 미결. 자극어 선택이 연상 공간을 규정한다. (C)로 최소화하거나, 검증의 셔플 대조군(자극어 무작위화 대비)으로 *사후 측정*한다.
- **RT 부재로 인한 민감도 손실:** 콤플렉스의 고전 지표(반응지연)를 버리고 내용·자기보고로 대체하므로, 자기보고하지 않은 무의식적 지연은 포착하지 못한다.
- **언어 유창성 교란:** 연상의 빈약함이 심리적 억압인지 단순 어휘력·상상 습관인지 단독으로는 가릴 수 없다 → ESM·다른 L1 모듈과 교차검증으로만 해석.
- **직교성 미확정:** [생성 은유와 문장 완성](generative_metaphor.md)·[클린 랭귀지](clean_language.md)와 같은 L1 축을 중복 측정할 위험. 중복이면 배터리 편입 대신 흡수/기각 대상.

## 5. UI 렌더링 명세 (Frontend Component)

- **UI 컴포넌트:** 단어 카드 스택. 한 번에 자극어 1개, 자동 확장 텍스트 입력.
- **상호작용:** 타이머·정답·점수 표시 없음(RT 미측정 원칙 가시화). "안 떠오름/넘어가기" 버튼을 항상 노출해 막힘도 1급 데이터로 존중한다.
